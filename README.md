Pada program ini, saya membuat sebuah **Aplikasi Kasir Warung Madura** menggunakan bahasa C++ untuk mensimulasikan proses transaksi penjualan yang biasa terjadi di sebuah warung. Melalui program ini, saya menerapkan beberapa konsep dasar pemrograman, seperti prosedur tanpa parameter, prosedur dengan parameter, fungsi dengan nilai balik, dan fungsi dengan parameter agar kode yang dibuat lebih terstruktur dan mudah dipahami. Pengguna dapat memilih barang yang ingin dibeli, menentukan jumlah pembelian, serta memasukkan nominal pembayaran. Selanjutnya, program akan menghitung total belanja, pajak sebesar 0,8%, diskon 5% untuk pembelian minimal Rp100.000, dan uang kembalian yang diterima pelanggan. Setelah transaksi selesai, program akan menampilkan struk pembelian secara otomatis serta memberikan pilihan untuk melakukan transaksi berikutnya. Melalui pembuatan program ini, saya dapat memahami bagaimana konsep fungsi dan prosedur diterapkan dalam pengembangan aplikasi sederhana yang dekat dengan kehidupan sehari-hari.


Konsep yang diterapkan dalam program:
- Prosedur tanpa parameter : Menampilkan daftar menu barang.
- Prosedur dengan parameter : Mencetak struk pembelian berdasarkan data transaksi.
- Fungsi dengan nilai balik : Menghitung total belanja dan pajak.
- Fungsi dengan parameter : Menghitung total tagihan setelah diskon dan pajak.
- Percabangan (if, switch) : Menentukan barang, diskon, dan validasi pembayaran.
- Perulangan (do-while) : Memungkinkan pelanggan melakukan transaksi berulang kali.
